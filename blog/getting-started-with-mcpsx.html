Getting Started with mcpz: A Comprehensive Guide

Jason Kneen
March 10, 2025
8 min read

mcpz is a powerful CLI tool that streamlines how you work with Context Protocol (MCP) tools. In this comprehensive guide, we'll walk through installation, basic configuration, and creating your first tool groups to optimize your AI workflow.

What is mcpz?

mcpz is a command-line interface designed to simplify the management of Context Protocol (MCP) tools. It allows you to organize your tools into logical groups, filter by use case, and significantly reduce token usage when interacting with AI models.

Installation

Installing mcpz is straightforward. You can use npm to install it globally:

npm install -g @mcpz/cli

Alternatively, you can use npx to run it without installation:

npx -y mcpz run

Basic Configuration

After installation, the first step is to run mcpz to connect to your MCP servers:

mcpz run

This command will:

  • Scan your environment for MCP servers
  • Connect to available servers
  • List all available tools
  • Analyze your workspace to recommend relevant tools
  • Start a server on stdio ready to handle requests

Creating Your First Tool Group

One of the most powerful features of mcpz is the ability to create logical groups of tools for specific tasks or projects. Here's how to create your first group:

mcpz create-group web-dev --smart

The --smart flag tells mcpz to analyze your project and automatically suggest relevant tools based on your codebase.

To see all your available groups:

mcpz list-groups

Using Tool Groups

To start mcpz with a specific tool group:

mcpz run --group web-dev

This will start mcpz with only the tools in the "web-dev" group, significantly reducing token usage and improving response times when working with AI models.

Advanced Configuration

mcpz offers several advanced configuration options:

Adding Tools to a Group

mcpz add-tools --group web-dev --tools "code-indexer_search_code,file-operations_write_file"

Removing Tools from a Group

mcpz remove-tools --group web-dev --tools "notification-server_broadcast_status"

Deleting a Group

mcpz delete-group web-dev

Best Practices

Here are some best practices for using mcpz effectively:

  • Create project-specific groups to optimize token usage
  • Use the --smart flag to leverage mcpz's AI-powered tool recommendations
  • Regularly update your groups as your project evolves
  • Use descriptive group names that reflect their purpose
  • Consider creating task-specific groups for specialized workflows

Conclusion

mcpz transforms how you work with Context Protocol tools, making your AI workflow more efficient and cost-effective. By organizing your tools into logical groups, you can significantly reduce token usage and improve response times.
